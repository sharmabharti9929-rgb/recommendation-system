# MovieFusion — Hybrid Movie Recommendation System

A full-stack movie recommender built from your trained Jupyter Notebook model.

## Architecture

Frontend: React + Vite + React Router + Lucide icons  
Backend: Flask + Flask-CORS  
ML: TF-IDF + cosine similarity + TruncatedSVD  
Dataset: MovieLens `ml-latest-small` or another standard MovieLens export.

The frontend calls Flask REST endpoints. The backend loads the exact artifacts produced by the notebook.

## 1. Prepare the ML artifacts

Run your Jupyter notebook completely. It should create:

- `tfidf_vectorizer.joblib`
- `svd_model.joblib`
- `content_sim.npy`
- `predicted_ratings.npy`
- `movies_processed.pkl`

Copy those five files into:

```text
backend/artifacts/
```

Copy MovieLens `ratings.csv` into:

```text
backend/data/ratings.csv
```

Also copy the same MovieLens `movies.csv` if you want to keep the raw dataset with the project; the backend primarily uses `movies_processed.pkl`.

## 2. Add movie posters

MovieLens does not provide poster images in the standard `movies.csv`/`ratings.csv` files. Therefore, the UI supports an optional:

```text
backend/data/posters.csv
```

Format:

```csv
movieId,poster_url
1,https://your-image-host.example/toy-story.jpg
2,https://your-image-host.example/jumanji.jpg
```

The poster URL must be publicly reachable by the browser. If no URL is available, the frontend displays a placeholder.

For a student/demo project, TMDB poster URLs can be added after obtaining the appropriate TMDB API access/permission. Do not scrape copyrighted poster assets without checking the source's terms.

## Pages

### Home
Introduces the project and links to personalized recommendations.

### For You
Select a MovieLens user and tune the hybrid balance.

`alpha = 0.6` means:
- 60% collaborative filtering
- 40% content-based filtering

The final recommendation list is sorted only by the fused hybrid score.

### Browse
Searches the MovieLens movie catalogue.

### Search

### About

## Important model note

Your notebook currently trains the final `predicted_ratings` using the complete ratings matrix, while the RMSE section separately trains an evaluation SVD on an 80/20 split. This is acceptable for a demo recommender, but the reported RMSE is an evaluation result and should not be described as the production model's RMSE unless the production model is also evaluated using a proper held-out protocol.

## Important poster note

Posters are not generated by the ML model. The recommender predicts movie IDs/titles/scores; the frontend simply displays poster URLs supplied through `posters.csv`.

## Troubleshooting

### CORS error
Make sure Flask is running on port 5000. The frontend expects:

`http://localhost:5000/api`

### Empty recommendations
Make sure:
- `ratings.csv` uses MovieLens column names.
- `movies_processed.pkl` was generated from the same MovieLens dataset.
- the requested user exists in `ratings.csv`.

### Missing artifact
Run the notebook again and copy all five artifact files into `backend/artifacts`.

### Posters not showing
Check that `posters.csv` exists, has `movieId,poster_url`, and the URLs are public HTTPS image URLs.
